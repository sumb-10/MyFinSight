# 화면 구성과 사용자 흐름

## 1. 공통 화면 구조

고정된 데스크톱 사이드바와 중앙 콘텐츠 영역을 사용한다. 주요 목적지는 `홈`, `투자 프로필`, `분석 리포트`, `모의투자`다. 기존 메뉴 이름은 저장소 확인 후 이 정보 구조에 맞춘다. 분석·리포트·모의투자 상세 화면에는 각각의 개별 식별자를 사용한다.

조건 확인과 분석 진행은 신규 분석 흐름 안의 단계다. 수정 요청은 리포트 또는 모의투자 상세에서 시작하는 오른쪽 패널로 제공한다. 출처·계산 상세도 오른쪽 패널을 활용한다. 패널을 닫으면 원래 읽던 위치와 키보드 초점으로 돌아간다.

## 2. 화면별 명세

| 화면 | 주요 정보 | 사용자 행동·다음 화면 | 필요한 상태 |
| --- | --- | --- | --- |
| 최초 프로필 설정 | 투자금·기간, 투자성향 질문, 손실 감내 수준, 관심산업·선호·제약 | 진단 → 조건 입력 → 저장 → 홈 | 필수값 누락, 범위 오류, 상충 제약, 저장 실패 |
| 프로필 요약·수정 | 최종 투자성향, 산출 성향과 변경 여부, 투자조건 | 수정 → 검증 → 저장 | 미등록, 저장 중, 저장 실패 |
| 홈 | 자연어 아이디어 입력, 적용할 저장 조건의 간결한 요약 | 분석 준비 → 보충 질문 또는 조건 확인 | 프로필 없음, 빈 아이디어, 입력 유지 |
| 보충 질문 | 부족·충돌·모호 항목 1개, 필요한 답변 | 답변 → 조건 재검사 | 질문 한도 도달, 취소 |
| 조건 확인 | 기본 조건, 이번 분석 값, 변경 항목, 지원 제약 | 조건 수정 또는 분석 시작 | 실행 불가능 조건, 미확정 항목 |
| 분석 진행 | 실제 단계 상태와 간단한 완료 내용 | 완료 → 리포트, 취소 → 홈, 실패 → 복구 | 진행·부분 완료·취소·실패·중단 후 재접속 |
| 리포트 목록 | 전략명, 원래 요청 요약, 분석 기준일·작성일 | 각 리포트 상세 | 없음, 로딩, 불러오기 실패 |
| 리포트 상세 | 상세 투자 판단, 근거, 구성·운용, 과거 성과·위험 | 출처 확인, 재분석, 조건 수정, 신규 결과의 모의투자 시작 | 저장된 결과, 미저장 결과, 조회 실패 |
| 모의투자 시작 확인 | 기준 리포트·전략, 시작일, 가상 자본, 통화, 구성·규칙 | 확인 → 별도 추적 객체 생성 → 상세 | 활성화 중, 실패, 재시도 |
| 모의투자 목록 | 전략명, 시작일, 최신 기준일, 가상 초기·현재 가치, 수익률, 같은 기간 비교지수·차이, 갱신 상태 | 각 포트폴리오 상세 | 없음, 로딩, 갱신 지연, 조회 실패 |
| 모의투자 상세 | 추적 이후 성과와 과거 백테스트, 현재 구성, 운용 규칙·재조정 기록 | 원본 리포트, 수정·재분석 | 갱신 지연, 데이터 실패, 지표 계산 불가 |
| 수정 패널 | 기준 전략, 현재 조건, 자연어 수정 요청, 관련 조건, 원안과 제안 변경 | 변경 조건 확인 → 수정안 분석 | 취소, 상충 조건, 보충 질문 |
| 비교 결과 | 조건·종목·비중·규칙 변화, 같은 조건의 성과·위험, 장점·불리한 점 | 신규 리포트, 신규 모의투자 시작 확인 | 비교 실패, 수정안 미저장 |

## 3. 프로필과 조건 입력

프로필은 하나만 존재한다. 필수 항목은 투자 가능 금액, 투자기간, 투자성향과 손실 감내 수준이다. 관심산업·선호조건·제약조건은 선택 항목이다. 시장 선택 화면은 만들지 않는다.

투자성향은 안정형·안정추구형·위험중립형·적극투자형·공격투자형의 5단계로 관리한다. 간이 진단 결과와 사용자가 선택한 최종 성향을 구분해 기록한다. 사용자가 다른 유형을 선택하면 차이를 짧게 설명하고 확인을 받는다. 공인 진단이나 투자 적합성 판정으로 표현하지 않는다.

제약조건에는 제외 종목, 전체 공통 최대 비중, 종목별 최대 비중, ETF 허용 여부가 포함된다. 자유 메모는 선호 해석에 쓰며 검증된 수치 제약처럼 취급하지 않는다.

기존 UC는 투자기간 1~10년과 공통 상한 5~100%를 제안하며 백엔드 모델도 관련 범위를 갖는다. 화면은 실제 계약의 검증값을 사용한다. 변경하기로 결정하면 입력·검증·조건 확인을 함께 바꾼다.

## 4. 신규 분석

1. 저장된 프로필을 불러온다. 없으면 프로필 등록으로 안내한다.
2. 사용자가 자연어 아이디어를 입력한다.
3. 프로필과 아이디어를 통합해 이번 분석 조건을 만든다.
4. 부족·충돌·모호 항목만 묻는다. 한 번에 한 항목, 최대 5회다.
5. 확정된 조건을 표로 보여준다. 프로필과 달라진 값은 표시한다.
6. 사용자가 `분석 시작`을 선택한 뒤에만 분석을 수행한다.
7. 검증을 통과한 결과를 리포트로 제공하고 저장 상태를 표시한다.

“NVIDIA를 적게 담고 싶다”는 요청에는 필요한 경우 비중 상한을 확인한다. 저장된 투자금·기간을 이유 없이 다시 질문하지 않는다. 5회 후에도 조건이 미확정이면 해당 항목과 수정 예시를 보여주고 분석을 중단한다.

분석 단계는 조건·자료 확인, 후보·규칙 구성, 전략 검증, 백테스트, 리포트 구성과 정합성 검사에 대응한다. 고정 자료 모드에서는 존재하지 않는 외부 검색이나 LLM 처리 횟수를 실행 기록으로 만들어내지 않는다.

## 5. 과거 리포트와 재분석

저장된 리포트는 당시 요청·조건·자료·규칙·결과를 유지한다. 현재 프로필을 변경해도 본문과 배분표가 바뀌지 않는다.

`같은 조건으로 재분석`은 해당 리포트의 조건을 가져와 다시 확인하고 새로운 결과를 생성한다. 과거 데이터 기준까지 재현하는 것과 조건은 유지하되 최신 자료로 다시 분석하는 것은 구분해 기준일을 표시한다. 원본은 보존한다.

과거 리포트 화면에서 곧바로 모의투자를 시작하지 않는다. 현재 정책에서는 분석 직후 새로 완료된 결과에서만 시작할 수 있다. 과거 리포트는 재분석 후 시작 확인으로 이어진다. 페이지 재접속 뒤 신규 결과 자격을 유지할지 여부는 구현 시 명시적으로 결정하고, 모든 과거 리포트에 시작 버튼을 자동으로 열지 않는다.

## 6. 모의투자

모의투자 객체는 완료된 결과에서 사용자가 시작 조건을 확인한 후 생성한다. 리포트 보기·종료·저장은 모의투자 시작 행동이 아니다.

목록은 전략을 찾고 상세로 진입하는 화면이다. 서로 다른 시작일의 수익률을 단순 평균하거나 최고 전략을 강조하지 않는다. 가상 포트폴리오 가치의 합계를 사용자의 실제 자산처럼 표시하지 않는다.

상세에는 `추적 시작 이후 성과`와 `과거 백테스트`를 구분한 두 뷰를 둔다. 생성 전 백테스트와 시작 후 가상 성과를 하나의 연속 곡선으로 합치지 않는다.

구성표는 시작 시 비중, 가격 변동 이후 현재 비중, 규칙이 산출한 목표 비중, 리밸런싱 시 적용 비중을 구분한다. 최초 배분 도넛을 계속 현재 구성으로 표시하지 않는다. 추적 전략 규칙은 보존하고 재조정 날짜·목표·적용 결과를 기록한다.

`원본 리포트 보기`는 추적의 기준인 변경 불가능한 리포트를 연다. `이 전략을 바탕으로 재분석`은 새 분석 흐름을 연다.

업데이트 주기와 최신 자료 기준일을 표시한다. 실제 갱신 방식이 뒷받침될 때만 “실시간”을 쓴다. 프론트엔드 고정 자료 모드에서는 앱 종료 중 자동 갱신을 약속하지 않는다. 향후 로컬 백엔드가 갱신한다면 그 프로세스가 전달한 상태를 표시한다.

## 7. 전략 수정과 비교

선택한 전략을 기준으로 자연어 수정과 관련 조건 편집을 제공한다. 모든 전략에 NVIDIA·현금 조절을 고정 노출하지 않는다. 이번 수정이 기본 프로필을 바꾸지 않는다는 사실은 변경 확인에 짧게 표시한다.

`변경 조건 확인` → 필요시 보충 질문 → `수정안 분석하기` → 비교 결과 순서를 따른다. 원안과 수정안을 동일한 백테스트 조건으로 재평가한다. 서로 다른 기간의 과거 리포트 지표를 나란히 놓고 공정한 비교라고 표현하지 않는다.

비교에는 추가·제외 종목, 비중 변화, 선정·배분·재조정 규칙, 성과·위험, 개선점과 불리한 점이 포함된다. 하나의 수익 지표 개선만으로 수정안이 전체적으로 더 낫다고 결론짓지 않는다.

수정 결과는 신규 리포트로 저장하며 원본 리포트와 기존 모의투자를 그대로 보존한다. 수정안 추적도 별도의 시작 확인을 거친다. 기존 추적을 자동으로 교체하지 않는다.

## 8. 오류와 복구

| 상황 | 보여줄 내용과 복구 |
| --- | --- |
| 입력 오류·상충 제약 | 해당 입력 옆에 원인과 수정 방법, 입력값 유지 |
| 일부 후보 자료 누락 | 제외 대상·사유를 관련 본문에 반영, 유효 결과는 제공 |
| 지목 종목·비교지수 등 필수 자료 실패 | 실패한 대상과 단계, 조건 수정 또는 사용자가 선택하는 재시도 |
| 실행 불가능 전략 | 원인 제약과 수정 진입, 자동 제약 완화 금지 |
| 백테스트·결과 정합성 실패 | 성공 리포트 생성 차단, 구체적 사유와 복구 행동 |
| 리포트 저장 실패 | 유효 결과를 유지하며 `저장되지 않음`, 저장 재시도 |
| 과거 리포트 조회 실패 | 해당 결과를 열 수 없다는 안내, 목록 복귀·재시도 |
| 모의투자 시작 실패 | 리포트 유지, 활성화 실패와 재시도 |
| 추적 갱신 지연 | 마지막 성공 기준일·현재 상태, 적절한 새로고침 |
| 앱 종료로 분석 중단 | 중단 상태와 기존 입력, 명시적 재시작; 자동 분석 재개 금지 |
| 지표 계산 불가 | `계산 불가`와 이유; 0·무한대·가짜 값으로 대체 금지 |

정상 결과의 투자 위험은 문단으로 설명한다. 저장 실패·조회 실패·잘못된 입력은 명확한 상태 메시지를 유지한다.
