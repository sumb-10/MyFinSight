## 3. 공시 사건을 뷰의 주 근거로 (뉴스는 보조)

사용자 결정 R1: 팀 DB에 뉴스는 적고 공시는 많다. 공시 사건(`disclosures` 표의 `event_type`·`available_on`)을 뷰·기업별 근거·시장 분석의 근거로 쓰고, 뉴스 헤드라인은 보조 근거로 둔다. 재무제표 표·뉴스 본문 발췌·회사 소개문은 이번 라운드에서 제외.

### 3-1. 근거 ID 와 선견(look-ahead) 규칙

- 공시 근거 ID 는 `dc<disclosure_id>` (뉴스는 그대로 `ev<news_id>`, 지표 `fin:`, 계산값 `calc:`). 인용 정규식은 새 `common/citations.py` 한 곳(`CITE_RE`)에 두고 네 곳(06 설명, 리포트 검증, 요구사항 점검, stub)이 같은 것을 쓴다.
- 날짜 기준은 **`available_on`(투자자가 볼 수 있게 된 날)**. 리밸런싱일 `d` 의 창은 `[d-45일, d)` 반개구간이라 `available_on == d` 인 공시는 들어가지 않는다(`published_at`=제출일은 표시용).
- 수정 공시(`is_amendment`)는 기본 제외. 사건 종류는 허용 목록(`DisclosureSettings.event_types`)만: 실적·자사주·배당·합병·주요 계약·증권 발행·경영권 변경·소송·풍문 답변·시설투자·구조조정·손상차손·부도·재작성·상장폐지 통지·감사인 변경 등 26종. **명시 제외**: `derivative_offering`(증권사 ELS, 7.3만 건 잡음), `offering_document`, `major_holder`, `proxy`, `related_party`, `shareholder_meeting`, `exhibits_only`. 06·14c 의 90일 요약에는 정기보고서·IR·기타 사건도 건수로 포함(`summary_extra_event_types`).

### 10-1. Black-Litterman 이 지금 하는 일 (코드 기준)

- **시장모형**(구성일 d 마다 새로): d 이전 252거래일 수익률로 공분산 Σ(수축 추정), 변동성, 시가총액 비중. 위험회피 δ 는 비교지수(SPY 등)의 같은 창 수익률에서 역산한 값 × 성향 배수(하한 있음).
- **기준(앵커) 비중** = 사용자가 고른 **기준 비중 규칙**(동일비중·시가총액·역변동성·최소분산)을 선정 종목에 적용하고 종목·섹터 상한을 건 비중. "시장 포트폴리오" 역할을 하는 것은 **전체 시장이 아니라 이 기준 비중**이다. 사전 기대수익률 π = δ·Σ·w_기준 (역최적화). 시가총액비중을 골랐을 때만 π 가 시총 가중 시장 포트폴리오에서 나온다.
- **뷰**: d 직전 45일 공시 + 14일 뉴스로 LLM 이 뷰를 만든다(시작일·현재 구성은 5세트 × 4뷰, 리밸런싱일은 1세트 × 4뷰). 코드가 근거 없는 뷰·범위 밖 값을 제거하고 신뢰도 상한을 건다.
- **사후 수익률**: 표준 BL(τ·Σ, Ω 는 신뢰도에서) → 효용 최적화(max w'μ − δ/2 w'Σw) with 종목·섹터 상한, 최소 비중, **종목당 이동 한도 |w − w_기준| ≤ 종목 상한의 1/3**. 뷰가 없거나 모두 제거되면 기준 비중 그대로(fallback).
- **리밸런싱마다**: walk-forward 는 모든 리밸런싱일에 시장모형·기준 비중·뷰·BL 을 그날 정보(t−1)로 **전부 다시** 계산한다. 종목은 백테스트 시작일 선정 목록으로 고정(K8). 직전 리밸런싱의 비중은 다음 계산에 쓰지 않는다(경로 의존 없음).
- 바꿀 수 있는 선택지(결정 필요): π 의 앵커를 기준 규칙과 무관하게 항상 시가총액 비중으로 둘지(교과서 BL), 이동 한도 1/3 을 성향별로 다르게 할지.
