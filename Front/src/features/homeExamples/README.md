# 홈 화면 시안 (예시 페이지)

홈 화면을 어떻게 바꿀지 비교해 보려고 만든 예시 페이지입니다. 기존 홈(`#/home`, `features/home/HomeScreen.tsx`)은 건드리지 않았습니다.
기존 홈과 같은 자료와 같은 서비스 호출을 쓰므로, 시안에서도 아이디어 입력 → 조건 확인 흐름이 실제로 동작합니다.

## 주소

개발 서버를 켠 뒤 (`npm run dev`) 목업 자료로 보려면 주소 앞에 `?mock=1` 을 붙입니다. 예: `http://localhost:5173/?mock=1#/home/1`

| 주소 | 파일 | 내용 |
| --- | --- | --- |
| `#/home/0` | `Example0.tsx` | 기존 홈 화면 구성·문구·동작 그대로, 톤만 토스풍 (배경 `#F2F5F7`, 테두리 없는 흰 카드). 맨 위 알약만 숨김. 글꼴·굵기는 기존 그대로 |
| `#/home/1` | `Example1.tsx` | 제목에서 무엇이 나오는지 말함. 입력 옆에 「이렇게 진행돼요」(분석 순서 5단계, 1단계 「지금 여기」, 세로선으로 연결 + 예시 리포트 링크) + 아래 기존 카드 3개. (예전 구성 B 의 흐름 띠는 시안 4 로 옮기고 지움) |
| `#/home/2` | `Example2.tsx` | 판 하나 안에 질문형 제목 → 5단계 진행 표시줄(가운데 정렬, 1단계 「지금 여기」) → 예시 카드 세 열(예시 아이디어 · 요즘 강한 섹터 · 내 투자조건) → 입력창. Enter 로 시작 |
| `#/home/3` | `Example3.tsx` | 좌우 분할. 왼쪽 입력 카드, 오른쪽 「내게 맞는 정보」 탭 카드. 첫 탭 「이렇게 진행돼요」에 5단계를 작은 화면 그림과 문장으로 (처음 쓰는 사람에게 먼저 열림) |
| `#/home/3?layout=b` | `Example3.tsx` | 같은 화면을 리포트가 있는 사람 기준으로 (첫 탭이 「요즘 강한 섹터」) |
| `#/home/4` | `Example4.tsx` | 「아이디어에서 모의투자까지 다섯 단계면 돼요」. 5단계 카드(작은 화면 그림 + 지금 내 상태와 그 화면 링크)와 입력 카드를 따로 둠. 예시·섹터 칩은 이름표 없이, 섹터 칩에 「한 달」 수익률. 내 투자조건은 입력 카드 아래 한 줄 |
| `#/home/4?layout=b` | `Example4.tsx` | 같은 구성, 단계 그림만 화면 그림 대신 토스페이스 아이콘 (화면 그림을 옮기기 전 모습) |

주소 뒤에 붙일 수 있는 값:

- `color=all` (시안 0·1·4): 버튼과 작은 글씨까지 전부 `#4880EE`. 없으면 강조만 `#4880EE` 이고 버튼은 기존 진한 파랑.
- `bare=1`: 화면 아래의 시안 전환 막대를 숨깁니다 (화면 캡처용).
- `prev=1` (시안 3): 「이렇게 진행돼요」 탭을 넣기 전의 「이전 버전」. 전환 막대의 「새 버전 / 이전 버전」으로도 바꿀 수 있습니다.

여러 값은 `&` 로 잇습니다. 예: `#/home/4?layout=b&color=all&bare=1`

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `index.tsx` | 번호에 맞는 시안을 고릅니다 |
| `shared.tsx` | 시안들이 같이 쓰는 자료·동작(`useHomeModel`), 화면 틀(`ExampleFrame`), 시안 전환 막대, 시안 목록(`HOME_EXAMPLES`) |
| `shared.css` | 시안 안에서만 쓰는 규칙: 버튼 글자 크기·굵기 클래스가 보이게, 입력창의 전역 외곽선 끄기, 한국어 단어 단위 줄바꿈 (아래 「알아둘 점」) |
| `toss.css` | 모든 시안의 톤 (색). 글꼴은 기존 화면과 같은 Noto Sans KR |
| `example0.css` | 시안 0 에서만: 카드 테두리·모서리·그림자 |
| `tossParts.tsx` | 시안들이 같이 쓰는 조각 (카드 모양, 입력 카드, 요즘 강한 섹터 한 줄, 5단계 작은 화면 그림 `MiniScreen`) |
| `tossface/` | 토스페이스 그림(SVG)과 라이선스 전문(`LICENSE.txt`). 그림을 쓰는 동안 라이선스 파일을 같이 둡니다 |

톤(`toss.css`)은 시안 화면이 켜져 있는 동안만 `<html data-home-example="…">` 을 달아 적용하고, 화면을 떠나면 지웁니다. 그래서 다른 화면의 색·폰트는 바뀌지 않습니다.

## 지우는 법

1. 이 폴더(`src/features/homeExamples/`)를 통째로 지웁니다.
2. 폴더 밖에서 고친 곳은 모두 `[홈 시안]` 이라고 적어 두었습니다. 그 줄을 지웁니다.
   - `src/app/router.ts`: `Route` 의 `home-example` 한 줄, `routePath` 의 `case "home-example"` 묶음, `parseRoute` 의 `#/home/1 …` 묶음
   - `src/app/App.tsx`: `HomeExample` 을 불러오는 한 줄, `Screen` 의 `case "home-example"` 한 줄, 사이드바 `active` 목록의 `"home-example"`
   - `src/app/router.test.ts`: `ROUTES` 의 `home-example` 한 줄
3. `npm run typecheck` 로 남은 곳이 없는지 확인합니다.

시안 하나만 지우려면 그 `ExampleN.tsx` 를 지우고 `index.tsx` 의 `case` 와 `shared.tsx` 의 `HOME_EXAMPLES` 에서 그 번호를 뺍니다.

## 알아둘 점

- **버튼 글자 크기.** `src/index.css` 의 `button, input, textarea, select { font: inherit }` 규칙이 Tailwind 글자 클래스보다 우선해서, 앱 전체에서 버튼의 `text-sm`·`font-semibold` 가 먹지 않고 16px·보통 굵기로 보입니다. 시안 화면 안에서는 `shared.css` 가 이를 되돌려 지정한 크기로 보여 줍니다. 기존 화면은 그대로 두었습니다.
- **상세 조건 창.** 화면 밖(body)에 그려지는 창이라 폰트와 색만 시안 톤을 따르고 모양은 기존과 같습니다.
- **둘러보기.** 기존 홈의 안내 단계를 그대로 씁니다. 시안에 없는 요소를 가리키는 단계는 말풍선이 화면 가운데에 뜹니다.
- **입력 초안.** 시안 1~4 에서 적던 글은 저장하지 않습니다 (기존 홈의 초안을 건드리지 않기 위해서입니다). 시안 0 은 기존 홈 화면을 그대로 그리므로 초안도 기존 홈과 같이 씁니다.
- **시안 0 의 버튼 글자.** 기존 홈과 똑같이 보이도록 위의 버튼 글자 크기 되돌림을 적용하지 않았습니다 (버튼 글자가 16px·보통 굵기).
- **테두리.** 시안 화면은 테두리 대신 면 색으로 나눕니다. 회색 배경(`#F2F5F7`) 위의 흰 면, 흰 면 안의 회색 면은 밝기 차이가 1.09:1 이라 테두리 없이도 구분됩니다. 기존 배경(`#F8FAFC`)과 흰 면은 1.05:1 이라 테두리를 지우면 카드가 묻히므로, 테두리를 지우려면 배경도 함께 바꿔야 합니다. 남긴 선은 카드 안의 구분선, 탭 기준선, 선택된 탭 밑줄처럼 정보를 나누거나 상태를 알리는 선뿐입니다.
- **입력창 포커스.** 테두리가 없으므로 입력하는 동안 상자 둘레를 파랗게 강조합니다. `src/index.css` 의 전역 `:focus-visible` 외곽선은 시안의 입력창에서만 끕니다 (`shared.css`).
- **글꼴.** 처음에는 Pretendard 를 썼지만, 굵은 제목이 기존(Noto Sans KR ExtraBold)보다 가벼워 보여 위계가 약해졌습니다. 그래서 기존 글꼴로 되돌리고 페이지 제목은 ExtraBold(800), 카드 제목은 Bold(700)로 맞췄습니다.

## 이전 버전과 되돌리기 (2026-11-15 노션 소개 반영)

노션 「튜토리얼 개선 사항」의 소개 화면(팀원 브랜치 `tutorial-improve` 의 `#/intro`)과 같은 5단계 순서를 시안 2·3·4 에 녹였습니다. (처음에는 시안 1 구성 B 에도 넣었지만, 그 흐름 띠를 시안 4 로 옮기고 구성 B 는 지웠습니다)
시안 2·4 의 반영 전 모습은 비교를 마치고 지웠고(파일은 저장소 밖 백업에만 있음), 시안 3 만 탭을 넣기 전 모습을 `Example3Prev.tsx` 로 남겨 두어 주소에 `prev=1` 을 붙이거나 전환 막대에서 바로 볼 수 있습니다.
시안 3 에는 왼쪽 카드 위에 5단계 진행 표시줄을 넣어 본 버전도 있었지만, 직관적이지 않아 빼고 오른쪽 「이렇게 진행돼요」 탭으로 바꿨습니다 (그 버전도 저장소 밖 백업에만 있음).

- **이전 버전으로 되돌리기:** `ExampleN.tsx` 를 지우고 `ExampleNPrev.tsx` 의 이름을 `ExampleN.tsx` 로, 함수 이름 `ExampleNPrev` 를 `ExampleN` 으로 바꿉니다. 그다음 `index.tsx` 에서 그 번호의 `Prev` 줄을 정리합니다.
- **새 버전으로 확정하기:** `ExampleNPrev.tsx` 를 지우고 `index.tsx` 에서 그 번호의 `prev ?` 분기를 뺍니다. 모든 번호를 확정하면 `router.ts` 의 `prev` 값과 `shared.tsx` 의 `ExampleVersion` 도 지울 수 있습니다.

새로 생긴 공통 부분 (`shared.tsx`):

- `PROCESS_STEPS`: 5단계 문구 (아이디어 적기 → 질문에 답하기 → 조건 확인 → 분석·검증 → 리포트·모의투자). 소개 화면과 같은 순서·뜻이라, 단계 문구는 여기서만 고칩니다.
- `GuideLinks`: 소개 화면 마지막 장의 세 가지 선택과 같은 안내 링크 (MyFinSight 소개 · 예시 리포트 · 화면 둘러보기).
- `INTRO_READY`: 지금은 `false` 라 「MyFinSight 소개」 링크가 숨어 있습니다. 소개 화면(`#/intro`)이 main 에 합쳐지면 `true` 로 바꿉니다.

둘러보기와의 관계: 팀원 브랜치는 홈 둘러보기를 8단계로 바꾸면서 `home-reports` 같은 위치를 가리킵니다. 시안 2·4 에는 최근 리포트 카드가 없고, 시안 3 은 「최근 리포트」 탭이 열려 있을 때만 있어서, 합친 뒤에는 그 단계 말풍선이 화면 가운데에 뜹니다. 고를 시안이 정해지면 둘러보기 단계도 함께 맞춰야 합니다.
