## 다섯 실행에서 공통으로 보인 것

**투자 결과**

- 허용 낙폭이 결과를 가른다. 2020년 3월 급락(−28~−33%)과 2022년 약세장(기술주 −43%)이 창에 들어 있으면 주식 100% 포트폴리오는 낙폭 20~25% 기준을 넘긴다. 통과한 두 시나리오는 기준이 30%·40%였거나(여행·에너지) 창이 2022년부터 시작해 2020년을 피했다.
- 현금 혼합안은 세 시나리오에서 유일한 통과 조합이었지만, AI의 "현금 47%"처럼 테마 노출을 절반으로 줄이는 대안은 의도와 충돌한다. 대안 제시에 함의를 함께 써야 한다.
- 종목·섹터 상한이 빡빡하면(종목 8~10%, 조정폭 2.7~3.3%p) 템플릿 4개와 BL 5개의 성과가 거의 같다. 상한이 느슨한 에너지(종목 20%, 조정폭 6.7%p)에서만 시나리오 뷰가 CAGR 5%p를 갈랐다.
- 뉴스 없이 LLM이 쓴 정적 뷰는 여행 시나리오에서 템플릿보다 전부 나빴다(hindsight 위험이 실제 성과로 확인). 뉴스 근거 뷰는 DB 기간(2026-09-27~) 때문에 마지막 리밸런싱 1회와 현재 구성에만 들어갔다.
- 섹터 상한은 테마 집중 포트폴리오에서 비중을 테마 밖 종목으로 밀어낸다(AI: IT 8종목 5%씩, 비IT 12%씩). 산업그룹 상한 또는 "테마 내 분산" 규칙 검토 근거.

**파이프라인 결함·개선 거리** (이번 실행에서 발견)

1. 현재 구성 뷰 생성에서 `long`이 빈 뷰가 오면 가드레일이 예외로 중단 → 형식 검사 가드 추가(수정 완료, `stage9_views.py`).
2. 리포트 헤더의 "기준 포트폴리오(동일비중)" 문구가 실제 기준(역변동성·최소분산)과 다름 → 템플릿 문구를 기준 id로 치환해야 함.
3. 추천이 없을 때 선택 포트폴리오 = 기준 템플릿이라 해석기가 "기준과 선택이 같다"고 지적 → 추천 없음이면 현금 혼합안을 선택으로 두는 안.
4. 같은 회사의 복수 주식 클래스(GOOG·GOOGL)가 동시에 선정됨 → 후보 단계에서 묶기.
5. 보조 비교지수 XLV가 테마와 무관 → 테마별 보조 지수 규칙.
6. 추정 창에 급락이 들어가면 시장 내재 δ가 작아져(에너지 1.21) BL이 조정폭 상한에 자주 걸림 → δ 하한 또는 장기 평균 사용 검토.
7. 넓은 테마(대형 우량주)는 후보 상한 120개가 걸림 → 상한 전에 지표 순 정렬. 좁은 테마(여행 21개)는 목표 종목 수가 선별력을 넘음 → 후보 수 대비 종목 수 안내.
8. 1년·반기 리밸런싱에서 종목·섹터 드리프트 주의(R4b·R5b)가 잦음 → 드리프트 허용치 또는 주기 안내.
9. 2022년 시장모형의 내재 기대수익률(항공 40~70%)이 커서 뉴스 뷰도 +50% 같은 큰 값이 나옴 → 뷰 수익률 범위를 내재수익률에 맞춰 조정.
