# 홈 시안 3 이식 · 질문을 홈 대화창으로 · 1~5 진행 단계 (2026-11-17 ~ 18)

홈 시안 3을 실제 홈에 옮기고, 새 분석의 보충 질문을 홈 화면 대화창에서 주고받게 했다. 최종 조건 확인만 따로 둔다.
브랜치 `feature/front-home-redesign`, 커밋 `013cccf`(이식·대화창·단계 표시), `e35fd07`(단계 물결).
각 항목은 "무엇을 / 왜 / 어디를(파일) / 어떻게 확인했나"를 적는다.

## 1. 문제

- 홈에서 「투자조건 확인하기」를 누르면 별도 질문 화면으로 넘어가 LLM 질문에 답하고, 다시 조건 확인 화면으로 갔다. 홈과 질문이 끊겨 보였다.
- 지금이 전체 흐름(아이디어 → 질문 → 확인 → 분석 → 리포트) 중 어디인지 알 수 없었다.
- 홈 위쪽 「진행 중이던 분석이 있습니다」 띠가 카드들과 따로 떠 보였다.
- 회의에서 「채팅창이 너무 좁다」는 의견 (1440 화면에서 약 490px).

## 2. 결정

- **시안 3 배치**: 왼쪽 「새 분석」 카드 + 오른쪽 「내게 맞는 정보」 탭(이렇게 진행돼요 · 요즘 강한 섹터 · 내 투자조건 · 최근 리포트). 실제 홈 내용(섹터 상자·기본 투자조건·최근 리포트)은 모두 탭 안으로 (사용자 결정: 프로필 탭에 실제 홈 내용 모두 살리기, 둘러보기는 탭 자동 전환).
- **위쪽 알림은 「이어서 할 일」 카드 하나로**: 진행 중이던 분석 · 취소한 분석(나머지 N건 보기).
- **질문은 홈 왼쪽 카드가 대화창이 되어** 주고받는다 (사용자 결정). **새 분석(mode `new`)만** 홈으로, 리포트에서 시작한 재분석·수정 요청은 기존 질문 화면 그대로.
- **주소는 그대로**(`#/analysis/:id`). 그리는 화면만 `ClarifyRoute` 가 고른다 → 질문 단계로 가던 5곳(홈 제출·이어서 하기·확인에서 되돌아가기·해석 재시도·목업 패널)을 고치지 않았고, 새로고침해도 대화가 이어진다.
- **1~5 단계 표시**(`FlowStepper`): 1 아이디어 적기 · 2 질문에 답하기 · 3 조건 확인 · 4 분석·검증 · 5 리포트·모의투자. 홈·질문·조건 확인·실행 화면 위쪽 (사용자 결정: 세 화면 모두). 예전 3칸 `FlowSteps` 는 지움.
- **버튼 이름** (사용자 결정): 홈 「분석 시작하기」, 조건 확인 「이 조건으로 분석 실행」.
- **넓히기** (회의 의견, 비율은 후보 A/B/C 중 B): 홈·질문 주소만 틀 폭 1180 → 1600px. 대화창 : 오른쪽 패널 = 1.3 : 1 (패널 최소 420px). 말풍선·입력창은 760px 까지.
- **말풍선** (사용자 결정, 여러 모양을 시험한 끝에)
  - 로봇 아이콘 없음. 꼬리 대신 말한 쪽 위 모서리만 직각, 나머지 14px.
  - 분석 모델 쪽 면 `bubble #eef1f4`. 처음 회색(흰 카드 대비 1.09)은 안 보이고 `#e9edf1`(1.18)은 진하다는 의견. 대화창 배경을 바꾸는 안은 바깥 회색 배경과 층이 뒤집혀 기각.
  - 경고·오류 말풍선도 면은 같은 회색, 앞에 색 아이콘만 (노랑·분홍 면은 알록달록해 보임).
- **단계 물결**: 지금 단계 동그라미 둘레로 연한 파란 물결이 2.4초마다 퍼졌다 사라진다. 움직임 줄이기 설정이면 멈춘다.
- **기다림 표시** (사용자 결정, 11-18): 점 세 개만 든 말풍선 + 말풍선 아래 작은 글씨.
  - 문구는 두세 단어(「답변 반영 중…」「다음 질문 준비 중…」「보탠 말 반영 중…」「조건 다시 확인 중…」), 아래 글씨는 반짝임.
  - 점(1.4초)과 반짝임(1.4초)은 같은 박자. 글씨는 보통 굵기, 가운데 점 「·」 없이.
  - 시간: 처음엔 문구만 → 5초부터 「답변 반영 중… 7초」 → 20초부터 「…, 조금 더 걸릴 수 있어요」. 3분 10초면 시간 초과 오류 + 다시 시도(기존).
  - 처음 해석 말풍선은 제목 앞에 같은 점, 5초부터 「해석 중 7초」.

## 3. 수정

### 화면

- **`features/home/RequestChat.tsx`(신규)**: 대화창. 내 아이디어 → 해석 중(점 세 개 + 서버 해석 단계) → 「이렇게 이해했어요」 → 질문. 보기를 누르면 바로 답을 보냄, 직접 적기·「답하지 않음」, 아래 입력창 「말로 보태기」, 카드 위 「조건 바꾸기」·「취소」(한 번 더 확인 후 홈에 아이디어를 다시 채움). 다 정해지면 조건 확인으로. 질문은 항상 하나씩(한꺼번에 답하기는 기존 질문 화면에만).
- **`features/home/chatParts.tsx`(신규)**: 말풍선(`BotSays`·`ISay`)·입력 중 표시(`Typing`)·말풍선 안 버튼.
- **`features/home/HomeScreen.tsx`**: 시안 3 배치, `request` 가 있으면 왼쪽 카드를 대화창으로. 질문 중에는 오른쪽 첫 탭이 「이번 요청 조건」, 「이렇게 진행돼요」 탭은 숨김(단계 표시와 같은 내용).
- **`features/home/HomeInfo.tsx` · `ProcessSteps.tsx` · `ContinueCard.tsx` · `home.css` · `tossface/`(신규)**: 오른쪽 탭, 진행 순서 그림, 이어서 할 일, 홈 전용 규칙, 💬 아이콘(라이선스 포함).
- **삭제**: `home/ResumeCard.tsx`, `home/SectorTrendsBox.tsx` (내용은 `ContinueCard` · `HomeInfo` 로).
- **`features/analysis/ClarifyRoute.tsx`(신규)**: mode `new` → 홈 대화창, 그 밖 → `ClarifyScreen`.
- **`features/analysis/FlowStepper.tsx`(신규)**: 단계 표시. 폭이 760px 보다 좁으면 지금 단계만 이름, 나머지는 번호(이름은 화면 읽기·마우스 올림으로).
- `app/App.tsx`(clarify 경로·넓은 틀), `analysis/ClarifyScreen.tsx` · `ConfirmScreen.tsx` · `Interpreting.tsx` · `flow.tsx`(FlowSteps 삭제, 기다림 문구), `run/RunScreen.tsx`(단계 표시), `tutorial/homeSteps.ts`(둘러보기가 탭을 열어 보여 줌), `index.css`(`.step-now` 물결).

## 4. 알아 둘 것

- 홈과 질문 화면이 서로 다른 컴포넌트(`HomeScreen` / `ClarifyRoute`)라, 대화창에서 취소하고 `#/home` 으로 돌아오면 홈이 새로 그려져 아이디어와 바꾼 조건이 입력창에 다시 채워진다.
- 팀원 브랜치 `tutorial-improve` 가 `HomeScreen.tsx` · `homeSteps.ts` 를 고쳐 병합 때 충돌이 예상된다.
- 토스페이스 💬 아이콘을 계속 쓸지는 아직 정하지 않았다.
