# input/

파이프라인의 최초 입력. `01_user_request.example.jsonc` 은 사용자 프로필 + 투자조건 + 자연어 아이디어를 담은 예시.

| 블록 | 역할 | 누가 소비하나 |
|---|---|---|
| profile | 투자자 자체 정보 (경험·지식·소득 안정성·비상금) | LLM: 설명 수준·보수성 조절, 가드레일: 위험 상한 보정 |
| capital | 투자금·통화·적립 | 전략 모듈: 배분금액 계산, 백테스트: 초기자본·정기납입 |
| horizon | 시작 시점·기간·유동성·목적 | 스크린 시점(as-of), 백테스트 기간, 리밸런싱 기본값 |
| risk | 성향·MDD 허용·목표수익·벤치마크 | 최적화 목적함수, 검증 모듈 판정 기준 |
| constraints | 하드 제약 (유니버스·종목 수·비중 상한·제외·리밸런싱) | 규칙 기반 검증(Pydantic), 최적화 제약 |
| strategy_preference | 템플릿·베이스라인 가중방식·뉴스 틸트 여부 | 전략 모듈 분기 |
| natural_language | 자연어 아이디어 | LLM: 테마 추출·종목 태깅·뷰 생성 |

규칙: `constraints` 는 절대 어겨선 안 되는 값, `risk`/`profile` 은 LLM이 해석해 반영하는 소프트 값.
