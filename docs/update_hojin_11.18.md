## 대화창에서 하는 일

- 내 아이디어(오른쪽 파란 말풍선) → 해석 중(점 세 개 + 서버 해석 단계 목록) → 「이렇게 이해했어요」 → 질문 말풍선.
- 보기를 누르면 바로 답을 보낸다. 직접 적기 · 「답하지 않음」(기본값) 도 된다. 질문은 항상 하나씩 (한꺼번에 답하기는 기존 질문 화면에만).
- 아래 입력창 = 「말로 보태기」. 카드 위 「조건 바꾸기」(상세 조건 창) · 「취소」(한 번 더 확인 후 홈에 아이디어를 다시 채움).
- 다 정해지면 조건 확인 화면으로 넘어간다. 질문 중에는 오른쪽 첫 탭이 「이번 요청 조건」(바뀐 조건 + 전체 조건)이고, 1~5 표시와 겹치는 「이렇게 진행돼요」 탭은 숨긴다.
- 주소는 그대로라 새로고침해도, 「이어서 할 일」에서 다시 들어와도 같은 대화로 온다.

# 알림 · 빈 화면 · 버튼 테두리 통일 (2026-11-18)

「테두리 있는 빨간 상자가 너무 AI 같다」는 의견에서 시작해, 앱의 알림 상자를 한 모양으로 맞췄다. 커밋 `0a192f0`.

## 새 기준

| 항목 | 기준 |
| --- | --- |
| 알림 상자 | 테두리 없음 · 둥글기 18px · 면은 연한 토큰 색(안내 tint · 주의 warning-tint · 오류 danger-tint · 성공 success-tint · 중립 sunken) |
| 글씨 | 제목 main · 본문 body. 예전처럼 진한 빨강·갈색 글씨를 쓰지 않는다 |
| 색 | 아이콘에만 (accent · warning · danger · success · sub) |
| 공용 부품 | `ui/index.tsx` 의 `Alert`(tone 에 `neutral` 추가, `icon`·`role`·`className` 받음). 직접 만드는 상자도 `NOTICE_BOX` · `NOTICE_ICON` 값을 쓴다 |
| 알림 안 버튼 | 새 `soft` 버튼(흰 면 · 테두리 없음). 되돌릴 수 없는 동작(요청 취소·중지 확정·취소 확정)은 꽉 찬 빨강 `destructive`(토큰 danger) |
| 빈 화면 | `EmptyState` 는 테두리 없는 흰 카드 (늘 회색 페이지 위). 공용 `Card` 는 그대로 |

## 바꾼 곳

- 공용 Alert 로 대체: 요청 중 오류(`ActionError`, 14곳) · 반영 결과(`ResultNote`) · 분석 실행 실패 · 연습 모드 띠 · 원화 수익률 안내 · 질문 화면의 「함께 바뀐 항목」·「바뀐 값 없음」. 원래 Alert·ErrorState 를 쓰던 43곳은 자동으로 바뀜
- 같은 색 값으로 테두리만 제거: 확인 상자 3개(반영하지 않은 추가 요청 · 모의투자 중지 · 분석 취소, 테스트가 찾는 `alertdialog` 이름은 유지) · 요청 취소 확인 · 기다리는 중 · 말로 보탠 결과 · 리포트 주의 상자 · 대시보드 알림 목록 · 리밸런싱 알림 · 예상 투자 일정 · 버전 비교 목록 · 「확인할 점」 줄 · 예시 리포트 안내 · 진행 중 단계 상자 · 분석 취소 완료 · 둘러보기 완료 · 리포트 패널의 자체 평가·검증 메모 · 모의투자 시작 창의 「이미 시작한 모의투자」 · 뉴스 반영 효과 안내 · 요청 내역 불러오기 실패
- 알림 안 버튼 12개: `secondary` → `soft`, 확인 상자의 `danger` → `destructive`. 리포트 삭제 확인 버튼도 같은 진빨강이 됨

## 일부러 그대로 둔 테두리

고르는 항목·선택 상태(질문 보기 카드, 전략 고르기, 단계 버튼, 필터 칩), 입력창, 태그·알약(목업·예시 표시, 상태 알약), 떠 있는 층(메뉴, 용어 말풍선, 둘러보기 말풍선), 흰 카드 위 버튼. 테두리가 「고를 수 있음/골랐음」이나 경계를 나타내기 때문이다.
